# Manim Presentation Style Guide


## Colors

 

x = GREEN

y = RED

z = MAGENTA

 

## Coordinate Plane

 

- Always use NumberPlane

- Label axes

- Use consistent scaling

 

## Animation Rules

 

- Use FadeIn for objects

- Use TransformMatchingTex when converting equations

- Avoid abrupt object creation

- Always do self.nest_slide() for every new step in solving a problem so it goes line by line

## Layout

 

- Titles always at top

- Examples centered

- Answers boxed in yellow

 
## Math
- Use MathTex whenever possible
- Avoid plain Text for equations

## Timing

- Keep animations under 2 seconds

- Pause after major steps

## Visual Theme

Background: Dark

Text: White

Graphs: Blue

Highlights: Variable dependent
